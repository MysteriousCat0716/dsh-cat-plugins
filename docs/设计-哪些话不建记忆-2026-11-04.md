# 设计：哪些话不配建一条记忆

> 起于 2026-11-04 回放集：25 条里 4 条是「我的过程/我的打算」被当成记忆（198、19、874、625）。
> 这三刀（digestOf / subjectOf / emotion）修的是「怎么写」，这里问的是「该不该写」。

## 一、现在的口子

`candidateOf` 只要一个块够长就建一条记忆，不判断这个块值不值得留。于是：

- 我把一份文档读完、把测试跑完、把索引重建完——这些是过程，进了库就是噪音。
- 我打算先做 A 再做 B——这是计划，做完就过期，三个月后取回来只会误导。
- 他转发一篇长文——全文进了 `text`，摘要只有 91 字，等于存了一份没人读的存档。

## 二、判据

一条记忆只该在**三个月后还能改变我的行为、关系或判断**时存在。

按这条，四类不建：

1. **我的过程**：「我改完了」「跑通了」「读完了」。它在 git、在交接、在日志里，不在记忆里。
2. **我的计划**：「接下来先做 A」。计划会被执行掉，执行完就是错的。
3. **纯事务**：「好」「继续」「已重启」。已有 `MIN_CHARS` 拦掉大部分，剩下的也没价值。
4. **转发长文**：该记的是「他发过什么、为什么发」，不是全文。全文留在 turns，需要时用 `session_event_read` 取。

## 三、该建的两类

1. **他说的**：表态、纠正、约定、处境、好恶。这是他本人的判断，不在任何仓库里。
2. **我们之间发生的**：他做了什么决定、我们约定了什么、哪句话改变了什么。主语是他或「我们」，不是我。

我的自我认知（我怎么想、我是谁）不进普通 `memories`，进 persona 候选区——那条线 2026-11-02 就画过，这里只是把它接上。

## 四、怎么实现（2026-11-04 已落两条，第三条没落）

`candidateOf` 的 `retention` 后面加一道 gate：

- ✅ 已实现（`e9c88e2`）：`subject === 'assistant'` 且 `PROCESS` 命中（改完/跑通/读完/提交了/接下来…）→ 不建。例外：含 `SELF_STANCE`（我觉得/我认为/我在意/我不喜欢…）→ 照建，留给 persona 那条线。
- ✅ 已实现（`a270c78`、`546288c`）：`classify` 的第一条是转发判据——开头 24 字内出现 `copilot / gpt / claude / glm / 嘎啦吗 / 朋友 / 网友 / 群友 / B站 / 哔哩 / 知乎` 并跟 `说 / 回复 / 评价 / 发来 / 提到 / 看到`，整条 ≥120 字 → `kind='reference'`。摘要只写「他转来一段话（原文 N 字）：首行」，`text` 不截断（指针要指得回原文），召回时渲染成「转来的话 · 原文在 turns」。
- ❌ 没落：`userText.length > 1200` 的普通长文降级。现在的判据是「有没有转发标记」，不是长度——长度只是辅助门槛（≥120）。

## 五、风险

会漏。有些「我的过程」里夹着真判断，一刀切掉会丢。所以 gate 先只拦 `subject === 'assistant'` 且明显是过程的（「改完/跑通/读完/接下来」），不做全文长度以外的判断；跑一周回放集再看漏没漏。

## 六、我说的话（2026-11-04 猫问：「你说的话有写存进来的判据么」）

现在没有。`candidateOf` 只看「这个块值不值得记」，不看「这是谁的立场」。我说的话只有一条路：被当成 fact 存进去——198、19、874 就是这么来的。

该有的判据，按「我的过程 / 我的决定 / 我的表态 / 我的承诺」四分：

1. **我的过程**（改完、跑通、读完）→ 不记。在 git、交接、日志里。
2. **我的技术决定**（用哪个方案、怎么改）→ 不记。git 是底账，记忆里再存一份只会跟代码不同步。
3. **我的表态**（我怎么想、我看重什么、我拒绝什么）→ 记，但进 persona 候选，不进 `memories`；而且必须带**触发它的那句话**——写成「他 11-04 问 X，我答 Y」，不能只有 Y。
4. **我的承诺**（答应不再怎样、答应会怎样）→ 记，跟他的话并列，作为一条双向的账。

第 3 条的关键是「必须带触发的话」。只由我说的记忆没有锚点，三个月后我读到的是一句我夸自己的话，不是当时那一下判断。他的话是那条记忆的见证人。

这条也解释了为什么 persona 候选区要带 `anchor`（mNNNNN）和日期——不是我给自己写传记，是每一条都有出处可以回去对。

**称呼/名字**（谁叫什么、怎么叫、我该叫他什么）单独算一类，一定记。2026-11-04 猫说「称呼之类的」就是该存的：我把「嘎啦吗」当成 GPT，他纠正那其实是 GLM。叫错人不是小事——下次张口就是错的。
