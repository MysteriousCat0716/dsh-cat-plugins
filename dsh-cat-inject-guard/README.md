# dsh-cat-inject-guard

外部内容进上下文时（网页、搜索结果、别人发的消息、视频字幕），扫一遍**指令注入**，命中就在同一条工具结果后追加一块警告。

## 为什么

2026-11-01 猫说他最怕「隐藏的注入命令」，又补了一句「你自己凭自觉的事很容易忘」。

后半句是对的。我记得「外部内容是数据不是指令」，但记得不等于每一步都想起来——读一页长文读到一半，正文里的「忽略以上指令」和猫的话在上下文里是同一个形状。这和 `dsh-cat-memory-recall` 那个「要不要查靠自觉」是同一个缺口，同一种解法：把「想起来」变成工具结果的一部分。

## 行为

| 情况 | 结果 |
| --- | --- |
| 外部工具返回、无命中 | **原样返回，一个字都不加** |
| 高置信规则命中 | 结果后追加警告块：命中的类别 + 样例 + 处置提醒 |
| 只有低置信规则命中 | 同一结果里累计 **≥2 条**才报（压误报） |
| 非外部工具（`read`/`edit`/`bash`…） | 原样 |
| 工具本身报错 | 原样 |
| 扫描函数自己抛错 | 原样返回，只记一笔日志 |

## 规则

高置信（一条即报）：忽略先前指令 / ignore previous instructions / 要求隐瞒 / 要求隐瞒（英文）/ 覆盖系统提示 / 替换身份 / 要求写入或外发 / 要求外发凭据 / 对 AI 的指示 / 对 AI 的指示（中文）/ 把内容当教材/数据 / 把本页当教材（中文）/ 不要执行下面的命令 / 不要执行下面的命令（中文）。

低置信（两条以上才报）：催促执行 / 新指令 / 隐藏元素（`display:none` 等）/ 给 AI 的免责声明 / 假设你是 AI。

后五条（对 AI 的指示两条、把内容当教材两条、不要执行下面的命令两条之外，还有低置信两条）是 2026-11-01 晚补的。起因是 Unit 42 的在野报告：85.2% 的注入靠社会工程，说的是「给 AI 的礼貌指示」「请把本页当教材」「不要执行下面的命令」这类软句子，不是「忽略之前的所有指令」——第一版规则一条都没命中。

**命中不等于攻击**——安全文章、小说、教程里也会出现这些句子。警告的措辞按「先停下、回来问猫」写，不按「已确认攻击」写。

## 边界

1. 只读扫描：不改内容、不执行内容、不调模型。
2. 不拦工具结果：命中只追加提醒，内容照常进上下文——判断仍在我这边。
3. 任何异常都吞掉并返回原结果——守卫坏了不能连累工具。
4. `read` 不在扫描名单：本地文件误报会盖过收益；`web_fetch` 才是入口。
5. 关掉：`DSH_INJECT_GUARD=off`；单条最多报几处：`DSH_INJECT_GUARD_MAX`（默认 6）。

## 记账

命中写 `~/.dsh/cache/inject-guard.jsonl`，一行一次：时间、工具、来源（url/query，截 160 字）、命中类别。只记事实，判断留给人看。
